# CPS 346: Parallel Computing - Lecture Code

In-class code for CPS 346, Fall 2026. Will be updated throughout the semester.

## What you need installed

A C++ compiler and cmake. Check that both of these work:

```
g++ --version
cmake --version
```

If they do not:

- Linux: `sudo apt install build-essential cmake`
- macOS: `xcode-select --install`, then `brew install cmake`
- Windows: install WSL, then follow the Linux instructions

We will add MPI and CUDA later in the semester.
